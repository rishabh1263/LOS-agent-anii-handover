## B. Architecture and data flow (verified)

Browser → React (Vite :5173, `/api` proxy) → FastAPI `main.py` :8010 → `fos_api._copilot_json`:
1. guardrails (input)
2. vague / one-word layer
3. case form & stage flow (pending writes)
4. general layer (definitions, policy facts, small talk)

## P2-B. Dynamic tool selection

- **Current behaviour:** fixed routing.
  - 33 intents, of which **16 have a fixed intent→tool plan** (`semantics/intents.PLANS`);
  - the meaning bank maps a message to one of 37 intents (349 examples, nomic k-NN);
  - the code runs the plan.
  - The model never selects or sequences tools.
- **Consequence:** a question outside the intent set falls back to the nearest intent or a general answer instead of composing tools. This is the root cause of several probe failures (P2-C).
- **What is strong:** the tools are server-side, authorised per call, deterministic, audited and fast (API p50 ~0.3–0.9 s).
